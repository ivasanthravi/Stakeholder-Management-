# Environment Audit (Phase 6)

**Date:** 2026-10-24. **Machine:** Apple M4, macOS (Darwin 25), Node 24.21.

## Application under test
| Item | State |
|---|---|
| Stack | React 19 + Vite 8 SPA, Hono API, Drizzle, PGlite (dev) or PostgreSQL 18.4 (embedded, tests/rehearsal), Better Auth, TanStack Query, Motion 14 (`motion/react`), Cytoscape 3.34 |
| Running locally | Dev servers: web `:5173`, API `:8787` (PGlite, sample workspace of 184 stakeholders). Started and verified before the audit |
| Production build | Built and served by `vite preview` for performance measurements, and through `scripts/staging-rehearsal.ts` (production artifact, HTTPS, real PostgreSQL) |
| Data | Synthetic only. Sample workspace (184 people); scale datasets of 73, 100, 1,000 and 5,000 people generated by the seed for the Universe measurements |

**Design system:**
- Tokens in `src/styles/tokens.css`: colour, type, radius, `--dur-*`, `--ease-*`.
- Shared components in `src/components/` (`ui.tsx`, `form.tsx`, `Menu`, `Picker`, `Drawer`, `BriefingView`), shell components in `src/shell/` (toasts, palette, copilot, inbox) and the peek panel in `src/screens/directory/`.
- Light-mode first.

**Motion system:** `src/lib/motion.ts` mirrors the CSS tokens. Durations are `instant 80`, `fast 140`, `base 200`, `slow 280` and `graph 400` ms, with standard, emphasized and exit easings.

**Architecture:**
- Route-level lazy screens (`main.tsx`), with a shell holding the nav, palette, copilot and peek panel.
- TanStack Query for server state; URL params for view state.
- Permission checks via `shared/permissions.ts` on client and server.
- RLS-scoped database access (`withTenant`).

## What cannot currently be tested

## Method notes
- **Below-the-fold capture:** screens scroll inside their own containers (`.prof-scroll`, `.page`), so Playwright "full page" screenshots equal the viewport. Below-the-fold content was reviewed with scroll captures and DOM inspection instead.
- **Measurement isolation:** performance measurements ran with the machine otherwise idle wherever possible. Where other work ran concurrently, the report says so.
